# Wimbledon Champions Dashboard

An interactive Tableau dashboard exploring Wimbledon champions, finalist seed positions, nationality patterns, and match-duration trends.

## Project Overview

This project analyzes Wimbledon championship data to explore patterns in champions, runner-ups, nationality, seeding, and match duration.

The dashboard includes views for gender-wise outcomes, champion and runner-up nationality, year-wise match duration, and finalist seed positions.

## Key Questions

- Which countries have produced the most Wimbledon champions and runners-up?
- How have finalist seed positions changed over time?
- How does match duration vary across years and genders?
- How do game margins and sets won differ between champions and runners-up?
- Are seeded players more likely to win Wimbledon finals?

## Dashboard Highlights

Gender-wise score and winnings -> Comparison of championship outcomes by gender
Championship winner nationality -> Countries producing Wimbledon champions
Runner-up nationality -> Countries represented among finalists
Year-wise match duration -> Trends in total match duration over time
Finalist seed positions -> Average champion and runner-up seeding by year

## Data Source

The dataset used in this project is the Wimbledon champions dataset available through the Tableau Public library.

- Dataset: `wimbledonclean.xlsx`
- Main fields: year, gender, champion, runner-up, nationality, seed, match minutes, game margin, and sets won
